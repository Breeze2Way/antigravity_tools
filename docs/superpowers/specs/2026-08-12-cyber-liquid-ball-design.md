# Codex Usage Widget 炫酷视觉设计

## 1. 目标

在保留当前 68×68 悬浮小球、小尺寸和低干扰特性的基础上，将界面升级为“霓虹液态能量球 + 悬停全息卡片”。默认状态保持紧凑，只有用户悬停时才展示完整信息。

## 2. 设计原则

- 小球是主视觉，百分比必须一眼可读。
- 颜色表达剩余量，水波和光效表达近期消耗速度。
- 详细数据放入悬停卡片，避免小球内部拥挤。
- 动画只增强状态表达，不改变查询周期、不影响拖动和其他操作。
- 数据读取失败时保持最后一次有效百分比，并用低调的灰雾状态表达不确定性。

## 3. 小球视觉

### 3.1 结构

从外到内分为五层：

1. 彩色环境光晕：颜色跟随剩余百分比，强度跟随近期 Token 消耗速度。
2. 细霓虹外圈：显示当前状态，低剩余时进入红色警戒呼吸。
3. 玻璃球底层：保留深色半透明背景，并使用当前渐变色轻微染色。
4. 液态水位层：保留现有水位和动态波浪，增加高光水线、透明叠层和少量气泡。
5. 中心读数：百分比使用白色高亮文字和轻微发光，保持水平居中。

### 3.2 颜色

沿用当前绿色 → 蓝色 → 黄色 → 红色的剩余量渐变，并将同一颜色用于：

- 水体主色
- 球体底色染色
- 外圈和光晕
- 悬停卡片的强调色

无有效官方百分比时使用灰蓝色，不显示伪造的彩色状态。

### 3.3 动画状态

- 正常状态：水波缓慢移动，外圈保持稳定微光。
- Token 消耗较快：水波振幅和速度增加，光晕轻微呼吸，气泡数量增加。
- 剩余量低于 20%：切换红色警戒色，外圈和光晕进行低频呼吸，不使用刺眼闪烁。
- 无数据或读取失败：球体降低饱和度，显示柔和灰雾，继续保留缓存百分比。
- 鼠标悬停：光晕略微增强，卡片淡入并向外上浮。

## 4. 悬停全息卡片

### 4.1 内容

卡片显示：

- 周剩余
- 近 7 天总量
- 近 30 天总量
- 更新时间
- 红色重置日期和整数小时，例如 `重置时间：2026-08-18 00:00 [剩余 132h]`

不再显示与周剩余重复的“状态”行。

### 4.2 外观

- 深色半透明磨砂背景
- 细边框和当前剩余量颜色的边缘光
- 圆角、轻微阴影和少量背景渐变
- 重置行使用红色强调，其余信息使用白色和蓝灰色分级
- 卡片宽度固定，文本自动换行，避免超出屏幕

### 4.3 交互

- 悬停约 150ms 后显示，避免鼠标掠过时频繁弹出。
- 鼠标移入卡片时保持显示。
- 鼠标离开小球和卡片后短暂延迟隐藏，避免闪烁。
- 不改变小球窗口位置，不阻止左键拖动和右键菜单。

## 5. 主题预留

第一版默认使用“霓虹蓝”主题，同时将颜色和光效集中到可替换的视觉配置中，为后续主题切换预留空间：

- 霓虹蓝：默认科技风
- 极光绿：更柔和
- 紫色赛博：高饱和炫酷风
- 熔岩红：警戒风格

主题切换不是第一阶段的必要功能，先保证默认主题完成度和性能。

## 6. 性能与兼容性

- 延续 WPF 自绘方式，不引入视频或外部运行时依赖。
- 动画只重绘小球和卡片，不触发官方用量查询。
- 无悬停时降低光晕和粒子更新频率。
- 继续使用现有用户活动暂停机制，任何视觉动画不得打断用户输入。
- 继续只读本地 Codex 数据，不读取或上传认证信息。

## 7. 验收标准

- 小球中心百分比在不同 DPI 和透明度设置下仍清晰居中。
- 40% 和 60% 的球体底色、液态颜色或光晕可明显区分。
- Token 消耗速度提高时，水波和光晕明显增强；停止消耗后逐渐恢复平静。
- 剩余量低于 20% 时有明显但不刺眼的红色警戒效果。
- 悬停卡片可完整显示统计信息和红色重置日期，且不重复显示状态行。
- 查询周期、缓存策略、拖动、右键菜单和后台读取行为不发生变化。
- 现有自动化测试全部通过，并为新增的状态映射和格式化逻辑补充测试。
